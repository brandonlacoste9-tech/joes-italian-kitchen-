# Joe's Italian Kitchen

Family-site preview of [joesitaliankitchen.ca](https://joesitaliankitchen.ca/).

Three open rooms: Almonte, Wellington West (1323 Wellington Street West — not the diner at 1385), and Preston Street. Reservations are their OpenTable links. This preview does not take tables.

Order online is their Mobi2go link for Almonte and Wellington. Preston has no Order Online item on their nav. Gift cards are Toast for Almonte and Wellington only.

```bash
npm install
npm run dev -- --port 3620
```
